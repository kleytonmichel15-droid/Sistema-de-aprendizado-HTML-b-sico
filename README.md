# Sistema de Aprendizado – HTML Básico

Site educativo feito só com **HTML e CSS** para quem está começando a aprender HTML. Cada página explica um tema com exemplos práticos e imagens.

## Páginas

| Página | Conteúdo |
|--------|----------|
| `home.html` | Página inicial: o que é HTML, por que aprender e o que será estudado |
| `estrutura.html` | Estrutura básica de uma página HTML (o "esqueleto") |
| `elementos.html` | Elementos e tags: anatomia, tipos e dicionário rápido |
| `formato.html` | Formatação de texto e criação de links (`<a>`) |
| `imagens.html` | Imagens, áudio e vídeo (`<img>`, `<audio>`, `<video>`) |
| `tabelas.html` | Listas e tabelas *(em construção)* |

## Estrutura do projeto

```
├── css/    # Estilos de cada página
├── html/   # Páginas do site
└── img/    # Imagens, logotipo e mapa mental
```

## Como usar

1. Baixe ou clone o repositório.
2. Abra o arquivo `html/home.html` no navegador.
3. Use o menu para navegar entre os estudos.

Não precisa instalar nada nem ter servidor.
